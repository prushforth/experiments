Theming a basemap by prefers-color-scheme, with media

This one has grown up and moved out. Two vector basemap layers over the same .pmtiles archive, one styled dark and one light, each gated by <map-layer media="(prefers-color-scheme: …)"> — no script, no theme switcher — is the Dark mode use case, where it is worked through in more variants than this page could hold.

The remote row is the one worth the trip: when the layer is a <map-layer src>, a layer whose media does not match is a document that never has to be fetched at all — which is the whole argument for the declarative form, and something no change handler can claim.

The matchMedia() counterpart stays here, because it is not covered there: it swaps the layer from a change handler, and it is the honest measure of what the attribute saves.
