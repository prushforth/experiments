Showing a layer by bounding box, with media

Press Capture this view and the page reads the map's extent, writes it into a six-term media query, and puts that query on the media attribute of the <map-layer> it creates. Then it stops: no matcher, no change handler, nothing left running. Zoom out past 14 and pan, and the captured rectangle still comes and goes.

Mechanism media attribute matchMedia() API

Variants Inline only <mapml-viewer> only

MapML.js (Leaflet)

The reference implementation. A layer whose media does not match is absent from the layer control, not merely unchecked in it.

MapML-MapLibre

The attribute is observed, so it can be set on an element that is already in the document — which is exactly what happens here.

MapML-OpenLayers

The map's view extent is already in projected coordinates, so the numbers written into the query are read straight off the view with no conversion.

This is the more interesting half of the pair, because the query is computed by script in both versions — the matchMedia one does the same arithmetic. What differs is only what happens next: there, a handler stays registered for the life of the page and has to keep the layer's checked and hidden in step with the query; here, the query is a value on an attribute and the user agent owns the consequences.

The same argument applies to a query that is not computed at all — a layer whose coverage the author already knows — which is the ordinary case and needs no script whatsoever.
