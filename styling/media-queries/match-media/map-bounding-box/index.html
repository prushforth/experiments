Showing a layer by bounding box, with matchMedia()

Press Capture this view and the page reads the map's extent, writes it into a six-term media query, and draws the captured rectangle as a new <map-layer>. A change handler then shows and hides that layer as the query goes in and out of match. Zoom out past 14 and pan: the rectangle joins and leaves the map, and the layer control with it.

Variants Inline only <mapml-viewer> only

MapML.js (Leaflet)

The reference implementation. The rectangle is drawn in projected coordinates (cs="pcrs") because that is what the media features are measured in.

MapML-MapLibre

Same query, same arithmetic. What differs is only how the resulting rectangle is drawn.

MapML-OpenLayers

An OpenLayers view extent already is in projected coordinates, so the numbers in the generated query can be read straight off the view.

The overlap test is the standard one — two rectangles overlap when each starts before the other ends, on both axes — which is four comparisons, here combined with a projection and a zoom term. It is long, but it is a value: a string that can be computed, stored, sent to a server, or written into an attribute.

Writing it into an attribute is exactly what the declarative version does, and it is the more interesting comparison of the pair: the query is generated by script either way, but only one of them needs a handler afterwards.
