prefers-color-scheme — light / dark theme switching

The same adaptive color-scheme experiment implemented two ways. Both run on the OpenLayers build of the MapML polyfill; they differ only in how the vector tiles are styled.

  • OpenLayers / MapLibre styles Styles the vector tiles with a Mapbox/MapLibre style-spec document (application/vnd.maplibre-style+json).
  • Leaflet / protomaps styles Styles the vector tiles with the protomaps-leaflet rules (application/pmtiles+stylesheet).
