Experiments

Media / map container queries

A map is an environment of its own: it has a projection, a zoom level and a bounding box, and the reader may prefer one kind of map content over another. These experiments query that environment the way CSS queries the viewport — with media features named map-projection, map-zoom, map-top-left-easting and friends, plus the preference features prefers-map-content, prefers-color-scheme and prefers-lang.

Feature tags

Mechanism by media feature

Every feature below is explored twice, because there are two ways to act on a map media query and they are not equivalent. The media attribute is declarative: the author writes the query on the element and the user agent decides whether that element participates at all. The matchMedia() API is procedural: the author registers the query, listens for change, and does whatever they like in the handler — including things the attribute cannot express.

What the two mechanisms are for

The attribute is the better answer whenever the question is which of several equivalent representations suits this map, because a non-matching element is really disabled: it is absent from the map, absent from the layer control, and — when it is a <map-layer src> or a templated <map-link> — never fetched. Nothing has to run for that to be true.

The API earns its keep when the response is not “use this element instead of that one”: rewriting a <map-style> as the zoom changes, computing a query string from the current extent, or swapping a page stylesheet — none of which an element-scoped attribute can do. Most of the pairs above are deliberately the same experiment written both ways, so the cost of each can be read off directly.

prefers-color-scheme is also explored inline and remote, as the Dark mode use case; and a projection media query drives change projection on zoom change.

prefers-lang is under review: language selection is what hreflang is for, and a language is arguably not a media feature at all. The two prefers-lang pages are kept as the record of that experiment.
