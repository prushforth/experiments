Dark mode

Two vector basemap layers over the same .pmtiles archive, one styled dark and one styled light, each gated by <map-layer media="(prefers-color-scheme: …)">. The map follows the colour scheme the user asked their operating system or browser for, the way the rest of the page does — no script, no theme switcher. The page declares itself compatible with both with <meta name="color-scheme" content="dark light">.

The two content types differ in more than parsing here: when the layer is a <map-layer src>, a layer whose media does not match is a document that never has to be fetched at all.

The media attribute is the layer-level equivalent of <link media> and of the media attribute of <source>: it is the author telling the user agent which of several equivalent representations suits the current environment. Media features that describe the map itself — map-projection, map-zoom, map-bounding-box — are explored in Media / map container queries.

See MapML.js issue 551 and the use case Customize the color scheme (light/dark or high contrast).
