Dark mode declared inline, in a <map is="web-map">

The same two media-gated layers as the <mapml-viewer> version, hosted by the customized built-in <map is="web-map">. Only the root element changes; media is an attribute of the layer, so it behaves identically.

MapML.js (Leaflet)

The reference implementation ships web-map.js as a full duplicate of mapml-viewer.js, so the two root elements are independent code paths that have to agree about the media gate.

MapML-MapLibre

The gate is implemented on the layer element and the renderer is told to add or drop the layer, so neither root element knows about colour schemes.

MapML-OpenLayers

Both root elements share one implementation through a class factory, so the viewer's matchMedia() — the source of the matcher — is literally the same method here.

Each map starts static, so scrolling past it does not zoom it. The lock button — controlslist="static" — releases it for panning and zooming.

is= is a customized built-in element, which Safari does not support; in WebKit these frames fall back to the element's child content rather than a map.
