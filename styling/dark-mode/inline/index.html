Experiments

Dark mode, declared inline

Each map below holds two layers over the same vector tile archive: a dark-styled one carrying media="(prefers-color-scheme: dark)" and a light-styled one carrying media="(prefers-color-scheme: light)". Change the colour scheme your system or browser prefers and the maps follow, live — the layer that stops matching takes itself off the map and out of the layer control.

MapML.js (Leaflet)

The reference implementation. Its pmtiles stylesheet is an ES module of protomaps-leaflet paint rules keyed by tile URL, so the two themes ask for the same archive under different query strings.

MapML-MapLibre

The stylesheet is a MapLibre style document, so the theme is data the renderer already understands; both layers name the same archive and differ only in the rel="stylesheet" they link.

MapML-OpenLayers

Same MapLibre style documents, applied to an OpenLayers vector tile layer. The matcher comes from the viewer's own matchMedia(), which is why a map-scoped feature could gate a layer the same way a user preference does.

Trying it

Set the preference in the operating system, in the browser, or in developer tools: in Chrome and Edge, DevTools → More tools → Rendering → Emulate CSS prefers-color-scheme; in Firefox, the light/dark toggle at the top of the Inspector.

<meta name="color-scheme" content="dark light"> in this page's head is what lets the browser render the surrounding document dark as well, so the map is not a bright rectangle in a dark page or the reverse.

Each map starts static, so scrolling past it does not zoom it. The lock button — controlslist="static" — releases it for panning and zooming.
