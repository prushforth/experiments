Dark mode, from remote MapML documents

The same two themes, but each layer is a whole MapML document — <map-layer media="(prefers-color-scheme: dark)" src="dark.mapml"> and its light counterpart. The page names both and the user agent picks; the document that does not match need never be fetched, which is what makes media more than a way of hiding things after the fact.

MapML.js (Leaflet)

Each document supplies its own title, licence and pmtiles stylesheet, so the page carries no theme-specific markup at all — only the media query that chooses between the two documents.

MapML-MapLibre

Remote MapML is parsed as XHTML, so attributes such as checked="checked" have to be spelled out in full; the layer's own <map-title> names it in the layer control.

MapML-OpenLayers

The fetched content lives in the layer's shadow root, so the media gate has to tear the whole layer down and build it again when the preference changes.

The two documents also link each other as rel="style" alternates, so a reader who wants the other theme can still choose it from the layer control — the media query supplies the default, not a restriction. That mechanism on its own is the Alternate basemap styles experiment.

Each map starts static, so scrolling past it does not zoom it. The lock button — controlslist="static" — releases it for panning and zooming.
