MapML.js (Leaflet)

The reference implementation, hosting the map chrome on a child element because an HTMLMapElement cannot attach a shadow root.

MapML-MapLibre

Same documents, same gate. Fetching is the layer element's job in every variant, so the four cells of this matrix differ only in who owns the map.

MapML-OpenLayers

One shared implementation behind both root elements, so this frame and the viewer frame exercise the same fetch, the same shadow root and the same matcher.

Each map starts static, so scrolling past it does not zoom it. The lock button — controlslist="static" — releases it for panning and zooming.

is= is a customized built-in element, which Safari does not support; in WebKit these frames fall back to the element's child content rather than a map.
