Alternate basemap styles

A National Geographic basemap that also offers satellite imagery, with and without place names, as alternate styles of the same layer. Each style is a MapML document that links the whole set — itself as <map-link rel="self style">, the others as <map-link rel="style"> — so the layer control can offer the choice and the layer can be swapped for the one the user picks.

There is no inline variant: rel="style" names an alternate document for the layer, so the layer has to be a document in the first place. Inline markup can be styled, but it cannot be exchanged for a different representation of itself.
