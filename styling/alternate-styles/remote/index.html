Experiments

Alternate basemap styles

One <map-layer src> naming a MapML document that offers itself as <map-link rel="self style"> and two siblings as <map-link rel="style">. The layer control turns those links into a radio group, and choosing one swaps the layer's document for the alternate — the same place, drawn from a different service, without touching the page.

Root element <mapml-viewer> <map is="web-map">

MapML.js (Leaflet)

The reference implementation: the style radios appear in the layer control under the layer's name, and picking one rewrites the layer's src.

MapML-MapLibre

Same radio group, same document swap. Every style here is WebMercatorQuad imagery, which is the one tiling this renderer can show.

MapML-OpenLayers

The radios are grouped per layer, so two layers offering styles cannot collide. Switching reloads the layer in place, keeping the promise an early whenReady() was waiting on.

Each document links every style in the set, including itself, so whichever one the author names is a complete entry point — the client discovers the rest from the document it was given. The same links are also what a user agent would need to remember a style preference across visits.
