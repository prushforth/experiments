The same layer documents as the <mapml-viewer> version, hosted by the customized built-in <map is="web-map"> instead. Only the root element changes; the style links, the layer control radios and the document swap they trigger are the layer's business, not the map's.

MapML.js (Leaflet)

The reference implementation ships web-map.js as a full duplicate of mapml-viewer.js, so the two root elements are independent code.

MapML-MapLibre

The newest of the three to implement the customized built-in, and the style radios come along with it — the layer control is built from the layer, not from the element hosting it.

MapML-OpenLayers

Both root elements share one implementation through a class factory, so the viewer and web-map versions exercise the same code apart from the host seams.

is= is a customized built-in element, which Safari does not support; in WebKit these frames fall back to the element's child content rather than a map.
