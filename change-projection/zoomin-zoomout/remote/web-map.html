MapML.js (Leaflet)

The reference implementation. Zoom all the way out and in again to pass through all four maps — but crossing between the Atlas of Canada map and the Canada Base Map, at zoom 5 to 6, it never settles. Changing the projection also moves the zoom by one, which puts the map back in the range of the map it just left, so the two keep swapping and nothing is drawn.

MapML-MapLibre

MapML-MapLibre draws Web Mercator only.

MapML-OpenLayers

The same four documents and the same four media attributes, drawn by OpenLayers. Here the zoom survives the projection change, so every boundary settles.

is= is a customized built-in element, which Safari does not support; in WebKit these frames fall back to the element's child content rather than a map.
