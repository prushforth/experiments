Default map projection

Nothing here says which projection to use: the map has no projection attribute, and the second layer says nothing about one either. Both get the default, Web Mercator — OSMTILE — and a layer that does not name a projection takes the map's, so it is never the odd one out.

The basemap offers the same area two ways, Mercator and Lambert; the Lambert one is listed under the layer's settings but disabled, because the map is not in that projection. The point layer is written after the basemap, so it is drawn on top of it.
