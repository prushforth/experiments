Negotiate map resource projection, from remote MapML

msi-cbmtile.mapml is written for Lambert Conformal Conic and names msi-osmtile.mapml, the same data for Web Mercator, with <map-link rel="alternate" projection="OSMTILE">. The button asks every map on the page for the same document; a map that is turned the other way follows the link and fetches the one that fits it instead.
