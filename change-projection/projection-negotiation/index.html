Negotiate map resource projection

A layer is written for one projection and names a version of itself for another with <map-link rel="alternate" projection="…">. One layer, written once, is added to maps that are turned different ways, and each map ends up with the version that fits it.

MapML.js and MapML-OpenLayers each show two maps of the same place, one in Web Mercator and one in Lambert Conformal Conic. MapML-MapLibre draws Web Mercator only, so its frame has the one map. In the inline variant it also never fetches the alternate, because it looks for one only when the layer itself came from a document; the other two look in both places, so that gap reads as a bug.
