Negotiate map resource projection, declared inline

The sea ice layer is written for one projection and names a version of itself for the other with <map-link rel="alternate" projection="…">. The button adds that one layer, written once, to every map on the page; a map that is turned the other way follows the link and loads the version that fits it.
