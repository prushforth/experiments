Localization of map UI, remote MapML in a <map is="web-map">

A <map> with one URL in it, chrome the viewer has to build outside its own shadow root, and a layer name that arrives from a second shadow root entirely. Three places the text could quietly come out English; if the whole control is still Ukrainian, none of them did.

MapML.js (Leaflet)

Two shadow roots: the one the <map> builds for its chrome, and the one the layer keeps its fetched document in. The layer control is written into the first and reads its label out of the second.

MapML-MapLibre

Customized built-ins are not implemented in WebKit, so in Safari this frame stays an inert <map> and never fetches the document at all.

MapML-OpenLayers

The hardest cell of the matrix, and the most ordinary-looking result: a layer named in Ukrainian by its server, inside a control named in Ukrainian by the page, inside a <map> element that cannot host either of them itself.

The layer name comes from <map-title> in un-clearmap.mapml; everything else in the control — the sub-layer's name, the opacity slider, both context menus — comes from the page's <map-options> table, or, in MapML-MapLibre, from its own bundled Ukrainian.
