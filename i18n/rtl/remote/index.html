What to try

  • Open the layer list and compare it with the same map written in the page. The layers should be named "CBMT" and "Ottawa Restaurants" either way — here those names are read out of the documents, and they have to land in the right place in a right-to-left list.
  • Change the cuisine. The menu is in the fetched document too, and the file it then asks for is named relative to that document, not to this page.
  • Unlock the map, open the menus, use the search box. Everything the maps draw should still be mirrored.
