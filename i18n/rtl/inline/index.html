What to try

  • Each map starts locked. Find the button that unlocks it — it should be on the right now, with the rest of the buttons on the left.
  • Open the layer list, open the cuisine menu inside it, and drag the opacity slider. Arrows, checkboxes and the slider should all run the other way.
  • Right-click the map, a layer and the cuisine menu for their menus, and open the search box. Menus should open from the right, and typing in the box should fill from the right.
  • Compare the three. Nothing here asks for a different layout in each, so any difference is the map library's doing.
