Right-to-left text

A page can ask for a right-to-left layout with dir="rtl". But a map's buttons, layer list, menus and search box are drawn by the map library, not written in the page, so whether they turn round is the library's decision.

The map is the same in all four: a basemap, a restaurant layer with a cuisine menu, a search box, and the map locked to begin with, so the first thing to find is the button that unlocks it.
