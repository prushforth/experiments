GeoJSON to MapML and back

Two GeoJSON feature collections, the population density of the United States and Canada's provinces and territories, turned into <map-layer>s by M.geojson2mapml() and added over a basemap. Its geometryFunction option gives each geometry a density class, which a <map-style> copied into each layer colours. The layers are then converted back with M.mapml2geojson(), and the bar above each map counts the features that came back.

What to try

  • Hover over a state or province for the caption geojson2mapml made from its name or PRENAME property, and click it for a popup of all its properties.
  • Open the layer control: each generated layer is named by the label option and can be hidden, reordered or made transparent like any other.

A class set on a <map-multipolygon> is not applied (Maps4HTML/MapML.js#688), so the geometryFunction sets it on each of the multipolygon's polygons instead. Every Canadian province or territory gets the lowest density class, as the Canadian data carries no density.

The United States data is us-states.js from Leaflet's choropleth tutorial; the basemap is Esri's National Geographic World Map, which Esri has retired to mature support.
