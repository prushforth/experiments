Experiments

A GeoJSON file handler, as a progressive web app, in a <map is="web-map">

The same apps as the <mapml-viewer> version, with the map hosted by the customized built-in <map is="web-map">, still inside a shadow root. Each frame is installed as a separate app from its <mapml-viewer> counterpart, with its own .geojson file handler.
