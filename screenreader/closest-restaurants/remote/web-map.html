Restaurant locations near Dows Lake, remote MapML in a <map is="web-map">

The cell with the least in the page: a <map> the browser only partly understands, a basemap and a restaurant layer that are both just URLs, and a place layer that does not exist until someone searches for it. If the features are still named tab stops afterwards, none of that mattered.

MapML.js (Leaflet)

Each remote layer keeps its fetched document in its own shadow root, inside a <map> whose chrome lives in another one. Neither should show up in the reading order.

MapML-MapLibre

No customized built-ins in WebKit, and no inline markup to fall back to — the most fragile of the four cells, and the one worth knowing about before shipping it.

MapML-OpenLayers

geojson2mapml() is a method of the viewer as well as a function on M, and the <map> gets it from the same mixin the <mapml-viewer> does.
