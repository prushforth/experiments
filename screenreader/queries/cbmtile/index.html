The same forecast and the same queries as the Web Mercator version, with the map, the basemap and the WMS requests all in CBMTILE (EPSG:3978), the Lambert projection the Canadian services are built for.

The reference implementation.

MapML-MapLibre

MapLibre now draws CBMTILE as well as Web Mercator, so the Lambert tiles and the EPSG:3978 WMS image line up here as they do in the other two, and the popup is again titled Feature.

MapML-OpenLayers

For the same place, the query returns the same rating here as in the other two, and as in all three Web Mercator maps: the projection changes the request, not the answer.

Trying it

As in the Web Mercator version: Tab to a map, press Enter or Space to query its centre, and focus moves to the popup; Escape returns it to the map. Outside the forecast area the service answers with its no-data value, -3.4028234663852886e+38, which is read out as if it were a rating.

The faint rectangle around Canada is drawn by the Lambert basemap's own tiles; it is not the fire danger layer's extent.
