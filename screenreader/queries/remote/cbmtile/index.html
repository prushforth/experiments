Experiments

Fire danger queries, in Canada Lambert, from remote MapML

The same maps as the inline version, except that the page says only <map-layer src="fire-danger.mapml"> for the fire danger layer. The WMS image and query templates, the style <map-select>, and the legend and licence links are in that document, which is how the service could publish a queryable layer for anyone to put on a page. The document also carries the layer's own extent, as a <map-meta name="extent"> in its <map-head>.

MapML.js (Leaflet)

The document names itself with <map-title>, so the layer control reads Fire Danger / Risque d'incendie without the page saying so, and the name still links to the legend from the document's <map-head>.

MapML-MapLibre

Remote MapML is XHTML, so the bare checked and selected attributes of the inline version are written checked="checked" and selected="selected": the same declarations, spelled the way an XML parser requires.

MapML-OpenLayers

The query link arrives in the layer's shadow root with the rest of the document and still answers the keyboard and the pointer: a fetched <map-extent> is as queryable as an inline one.

Trying it

As in the inline version: Tab to a map, press Enter or Space to query its centre, and focus moves to the popup; Escape returns it to the map. All three send the service the same GetMap and GetFeatureInfo requests as they do inline.

The basemap layer is still inline and hidden, so the layer control lists only the remote layer. Each frame fetches its own copy of fire-danger.mapml, so that View code and Open full page show a self-contained example; the three copies are identical.
