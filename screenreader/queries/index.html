Fire danger queries

A query asks a map what is at a point. With a pointer, the point is wherever you click; without one, it is the centre of the map, queried with Enter or Space once the map has focus. Either way the answer, here the forecast fire danger rating from a WMS GetFeatureInfo request (<map-link rel="query">), opens in a popup that takes focus, so a screen reader reads it without the reader having to go looking for it.

The two columns are the same layer, from the Canadian Wildland Fire Information System, requested in two coordinate reference systems: EPSG:3857 and EPSG:3978. Each map has a Canada Base Map underneath in the matching projection, marked hidden so the layer control offers only the layer there is something to ask about. In the remote versions the fire danger layer is <map-layer src="fire-danger.mapml">, a document holding its image and query templates, style, legend and licence.

The response is GeoJSON with no geometry, only properties, which each implementation places at the point that was queried. Outside the forecast area the service answers with a no-data value rather than nothing, and that number is what a screen reader hears.
