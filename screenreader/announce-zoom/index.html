Announce zoom

A map that says where it has got to. With <map-options>{"announceMovement": true}</map-options> the viewer keeps a visually hidden <output role="status"> and writes into it whenever the map settles: the new zoom level, or which edge of the content you have run off. A sighted user reads the map; a screen reader user is told the same thing in words, which is otherwise the part of panning and zooming that simply does not arrive. The map is searchable too, because being moved somewhere you did not pan to is the case where an announcement matters most.

The content type decides where the map's search service is declared. Inline, the page writes <map-link rel="search"> and <map-link rel="suggestions"> on the layer itself. Remote, they are in the fetched layer document, so a layer arrives knowing how it can be searched and the page never names the gazetteer it is using. Either way the page only asks for the box, with controlslist="search".

The results list and the move to the chosen place are each implementation's own default handling of the cancelable mapsearch and mapsuggestions events — there is no page script here. An author who wants a different results UI calls preventDefault() and renders event.detail.responses, or hands items back through event.detail.setResults().
