Restaurant locations in Ottawa

A layer of restaurants over a basemap, filtered by cuisine. Everything a pointer user does here is markup that a keyboard and a screen reader can reach as well: the restaurants are <map-feature> elements fetched through a <map-link rel="features"> template, each a tab stop named by its <map-featurecaption> and describable by its <map-properties> table; the cuisine filter is a <map-select> in the layer control, which is an ordinary <select> as far as assistive technology is concerned; and the basemap layer is hidden, so the layer control offers only the layer there is something to do with.

The content type matters to more than the parser here. Inline, the <map-select> and its template are children of the page. Remote, they are children of a fetched document that the layer keeps in a shadow root, and the layer control has to reach across that boundary to build the same form controls — a place where a filter has more than once gone missing without the map looking any different.

All four cells request the same feature documents from shared/restaurants/ — one per cuisine, plus restaurants.mapml for all of them — so what varies is only how the map is declared, never the data.
