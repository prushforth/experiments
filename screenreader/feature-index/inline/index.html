Experiments

Feature index, over features declared inline

Eight restaurants written in the page, and a reticle at the centre of each map naming the ones it covers. The list is a live region, so it is re-read on every move; the number beside a caption is the key that opens that feature. Nothing in the map markup asks for any of this — the index is switched on by a <map-options> preference, and what it can say is decided entirely by whether the features have <map-featurecaption>s worth reading.

MapML.js (Leaflet)

The reference implementation. The feature index control began in the ports and was taken back upstream, so all three frames now carry the same megaphone button and the same rule: the reader's preference wins, and the button shows the megaphone greyed out and ignores clicks. In all three the index is focus-gated: nothing is shown until the map is focused. MapML.js used to stay silent on a static map, because Leaflet's keyboard handler, which static switches off, is also what tells the map it has focus; a static map now keeps telling it.

MapML-MapLibre

MapLibre added the megaphone control (controlslist="featureindex") for readers who want the index on one map rather than all of them. Every frame shows it, but the index is still switched on the same way in all three — by the preference — so the button only reports that: a greyed megaphone that ignores clicks, still reachable with Tab so a screen reader can say it is on and unavailable.

MapML-OpenLayers

Features are drawn to a canvas, so the index cannot be read off the document: it is computed from the view extent each time the map settles, and the numbered keys are bound to the map viewport rather than to any feature.

Trying it

Each map starts static, so scrolling past it does not zoom it. Tab into any of the three and the reticle and its list appear all the same: static stops the map moving, not the index. Release the lock with the lock button to pan, or zoom out, and more of the eight restaurants fall inside the box.

With the keyboard alone: Tab to a map, release the lock, then use the arrow keys to pan. The list is re-read after each move. Press 1–7 to open a listed feature, 9 for the next page when more than seven are covered and 8 to go back, and Escape to close a popup.

Turn the preference off — remove the <map-options> script from the framed page — and the maps are unchanged in every other respect, except that the megaphone button comes alive: it starts crossed out, and pressing it turns the index on for that map alone and returns focus to the map so the list is read. That is the point: the index is the reader's, not the author's, and it has nothing to work with that a pointer user was not already given.
