The MapML.js and MapML-OpenLayers maps show the territorial evolution of Canada, drawn for Canada's Lambert projection. MapML-MapLibre draws Web Mercator only, so it shows different data instead — the probability of annual minimum snow and ice, over a Web Mercator base map that is marked hidden so the layer list holds only the layer with the chooser. The chooser works the same way either way, which is the point here; the projection is not.
