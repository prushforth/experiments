Vector tiles: pmtiles archives and MVT tiles

A .pmtiles archive and a {z}/{y}/{x}.mvt template over Spearfish, South Dakota, in MapML.js, MapML-MapLibre and MapML-OpenLayers. The same content is published four ways: inline MapML is parsed as HTML and remote MapML as XHTML, and either can be hosted by <mapml-viewer> or by the customized built-in <map is="web-map">. Each combination is a different code path, so each gets its own three-way comparison.

Content type by root element
<mapml-viewer> <map is="web-map">
Inline All three implementations MapML.js and MapML-OpenLayers
Remote All three implementations MapML.js and MapML-OpenLayers

MapML-MapLibre does not implement <map is="web-map">, so it appears in the viewer comparisons only.
