Experiments

Vector tiles declared inline, in a <map is="web-map">

The same inline markup as the <mapml-viewer> version, hosted by the customized built-in <map is="web-map"> instead. The layer markup is identical; only the root element changes, and with it the way the implementation has to host the map (an HTMLMapElement cannot attach a shadow root, so the map chrome goes in a child element).

MapML.js (Leaflet)

The reference implementation ships web-map.js as a full duplicate of mapml-viewer.js, so the two root elements are independent code.

MapML-MapLibre

The same MapLibre style document as the viewer version; the vector tiles are the renderer's own format, so the root element makes no difference to them.

MapML-OpenLayers

Both root elements share one implementation through a class factory, so the viewer and web-map versions exercise the same code apart from the host seams.

is= is a customized built-in element, which Safari does not support; in WebKit these frames fall back to the element's child content rather than a map.
