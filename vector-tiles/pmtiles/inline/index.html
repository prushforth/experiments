Experiments

Vector tiles declared inline

A .pmtiles archive and a {z}/{y}/{x}.mvt template, both declared as <map-link rel="tile"> in the HTML page itself, so the markup takes the HTML parsing code path. The same content is also available as remote MapML, where the layers are fetched as XHTML.

Inline Remote

MapML.js (Leaflet)

Styled with type="application/pmtiles+stylesheet" — a protomaps-leaflet rules module. Its 512 px tiles put the data one zoom level ahead, which is why this map opens at zoom 12.

MapML-MapLibre

Styled with a MapLibre style document (type="application/vnd.maplibre-style+json"), the format the renderer speaks natively.

MapML-OpenLayers

The same MapLibre style document, applied through ol-mapbox-style. MVT tiles use the extent's 256 px tile grid, so tilematrix zoom matches map zoom and the map opens at zoom 11.

Inline layers cannot offer the alternate-style switching the remote version does: rel="self style" / rel="style" swap one MapML document for another, which requires the layer to be a document.
