Vector tiles from remote MapML documents

The same .pmtiles archive and {z}/{y}/{x}.mvt template, but each layer is a <map-layer src> pointing at a MapML document that is fetched and parsed as XHTML — a different code path from the inline version, and one each implementation has to get right separately.

Content type Inline Remote
Root element <mapml-viewer> <map is="web-map">

MapML.js (Leaflet)

dark.mapml carries the protomaps-leaflet rules module and the archive; mvt.mapml carries the tile template. Open the layer control to switch the basemap between the dark and light documents.

MapML-MapLibre

Same documents, with a MapLibre style document as the stylesheet. The style choice comes from rel="self style" and rel="style" links in each document's <map-head>.

MapML-OpenLayers

Same documents again. Remote content is grafted into the layer's shadow root, so the style link and the tile link are found on a different root than in the inline version.

The map markup in the page is nearly identical across the three — the differences are inside the linked MapML documents, in the stylesheet type each implementation understands.
