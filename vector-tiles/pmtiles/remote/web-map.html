Vector tiles from remote MapML, in a <map is="web-map">

The same <map-layer src> documents as the <mapml-viewer> version — literally the same files in the same folders — hosted by <map is="web-map">. This is the cell where both variations meet: remote content grafted into a shadow root that hangs off a child of the <map> rather than off the map element itself.
