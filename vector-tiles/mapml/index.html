MapML vector tiles styled with a CSS stylesheet

Natural Earth country polygons published as text/mapml tiles (<map-link rel="tile" type="text/mapml">) and coloured by an ordinary CSS stylesheet linked with <map-link rel="stylesheet">. The same data is tiled two ways, WorldCRS84Quad and WebMercatorQuad, so the two maps on each page show the same countries in different projections.

Content type by root element
<mapml-viewer> <map is="web-map">
Inline All three implementations MapML.js and MapML-OpenLayers
Remote All three implementations MapML.js and MapML-OpenLayers

MapML-MapLibre does not implement <map is="web-map">, so it appears in the viewer comparisons only.

Inline or remote, the tiles themselves are always MapML documents fetched and parsed as XHTML; what changes is whether the layer is markup in the page or a document of its own. Only a document can offer <map-link rel="alternate">, which is how the remote version lets one layer serve a map in either projection.
