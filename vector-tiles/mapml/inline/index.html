Experiments

MapML vector tiles declared inline

Natural Earth country polygons served as text/mapml tiles and coloured by an ordinary CSS stylesheet, linked with <map-link rel="stylesheet">. Each frame holds the same content twice: a WorldCRS84Quad (WGS84) tile set above, and the WebMercatorQuad (OSMTILE) tile set of the same data over OpenStreetMap below.

MapML.js (Leaflet)

The reference implementation, and the reason the stylesheet is written the way it is: features are rendered as SVG, so g[data-fid="…"] > path selects a feature's geometry directly.

MapML-MapLibre

Two gaps show here. <map-link rel="stylesheet"> is not implemented yet — only <map-style> and the MapLibre style JSON used by the pmtiles and MVT layers are — so the features draw with default styling. And the renderer is Mercator only: the WorldCRS84Quad map falls back to OSMTILE and its tiles, which exist in WGS84 alone, have nothing to draw.

MapML-OpenLayers

OpenLayers draws features to a canvas, so there is no per-feature DOM for CSS to select. The same stylesheet still applies: the port resolves it against a hidden SVG mirror of the MapML.js shape and converts the computed values to OpenLayers styles.

The layers are declared inline, but each tile is itself a MapML document fetched and parsed as XHTML, holding the features clipped to that tile. The colours come from the layer's stylesheet, keyed on each feature's id, so a country keeps its colour across the tiles it is split over.
