Experiments

Non-geographic image map, declared inline

Henri Rousseau's The Banks of the Bièvre near Bicêtre, cut into TMS tiles and treated as a map. Nothing in it is on the Earth: WGS84 is being used as a flat coordinate system for a canvas, which is what makes the painting's figures addressable. Each figure is a <map-feature> whose geometry is wrapped in a <map-a>, so the feature is a link — styled link-blue by default, focusable, and announced as a link.

Content type Inline Remote

MapML.js (Leaflet)

The reference implementation of the tms attribute: the same template with the row axis counted from the bottom instead of the top, which is the whole difference between a TMS tile set and a WMTS one.

MapML-MapLibre

MapLibre renders Web Mercator only. The viewer warns that the WGS84 projection is unsupported and falls back to OSMTILE, which no amount of tiles of a painting can survive.

The gap is the finding: a map of something that is not the Earth needs a renderer that will accept a coordinate system it was given rather than one it assumes.

MapML-OpenLayers

Two features occupy the same girl: one for zooms 2 to 4, one for 5 to 8. Only one of them is ever drawn, ever hit-tested and ever a tab stop — the same detail that decides what a screen reader finds at each scale.

What to try

  • Each map starts static, so scrolling past it does not zoom it. Release it with the lock button before any of the following — while it is locked the map takes no keyboard pan or zoom, and a fragment link has nowhere to take you.
  • Tab into the map and onto Girl, Boy or Parents, then press Enter. The children's links are fragments — href="#5,-158.518400,-74.697610" — so they navigate within this map, zooming to a place in the painting rather than leaving it.
  • Zoom in past 5 and press Enter on the girl again: it is a different feature now, and its <map-a href="https://example.org/" type="text/html"> leaves for a document. Same figure, different representation, different behaviour.
  • Zoom past 4, where the tiles run out and the image is scaled instead — a declarative version of a responsive image that the layer, not the page, decides.

The tiles come from TiledArt-Rousseau and are served TMS-style, which is what the bare tms attribute on the <map-link rel="tile"> declares.
