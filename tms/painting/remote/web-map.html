Non-geographic image map, remote MapML in a <map is="web-map">

A <map> with two URLs in it. These frames fetch the very same painting.mapml and people.mapml as the <mapml-viewer> page beside them — a tiled artwork and the figures found in it do not care which element ends up showing them.

Content type Inline Remote
Root element <mapml-viewer> <map is="web-map">

MapML.js (Leaflet)

The linked figures arrive in the layer's shadow root, inside a <map> that keeps its chrome in another one, and are still ordinary links to tab through.

MapML-MapLibre

MapLibre renders Web Mercator only, and in WebKit the customized built-in <map> does not upgrade — no projection, no root element, and nothing in the page to fall back to.

The most fragile of the four cells, and the one worth knowing about before shipping it.

MapML-OpenLayers

Both root elements share one viewer here, so the TMS row flip, the zoom-ranged features and the link handling are the same code in this frame as in the other three cells.

Related: TMS maps uses the same attribute on geographic content, where the row flip is the only thing you notice.
