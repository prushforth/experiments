Non-geographic image map, from remote MapML

The same painting and figures, except that the page says only <map-layer src="painting.mapml"> and <map-layer src="people.mapml">. The tile template with its tms attribute, the zoom range that permits scaling past the last tiles, and the four linked figures are all in documents — which is how a collection would publish a tiled artwork for anyone to put on a page.

Content type Inline Remote
Root element <mapml-viewer> <map is="web-map">

MapML.js (Leaflet)

Each document names itself with <map-title>, so the layer control reads Painting and People without the page saying so.

MapML-MapLibre

MapLibre renders Web Mercator only, so the WGS84 painting is unsupported however it is delivered.

Remote MapML is XHTML, so the bare tms attribute has to be written tms="tms" — the same declaration, spelled the way an XML parser requires.

MapML-OpenLayers

The figures' fragment links still navigate the map that is hosting them: a <map-a href="#zoom,lon,lat"> in a fetched document is about the map it has been added to, not about the document it came from.

Splitting the artwork from the annotations is the point of the two documents: the tiles are one publication and the figures identified in them are another, and a page can take one, the other, or both. Remove People from the layer control and what is left is a picture; put it back and the picture has content in it again.
