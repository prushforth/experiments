Non-geographic image map

Henri Rousseau's The Banks of the Bièvre near Bicêtre, cut into TMS tiles and treated as a map. Nothing in it is on the Earth: WGS84 is being used as a flat coordinate system for a canvas, which is what makes the figures in the painting addressable. Each figure is a <map-feature> whose geometry is wrapped in a <map-a>, so the feature is a link — link-blue by default, focusable, announced as a link — and the girl on the path is two features, one for the zooms where she is a shape and another for the zooms where she is a person.

The remote variant splits the work the way a collection would publish it: the tiled artwork is one document, the figures identified in it are another, and the page only names them. It is also where the tms attribute has to be spelled tms="tms", because remote MapML is parsed as XML.

MapML-MapLibre has no column in any of the four cells: it renders Web Mercator only, warns that WGS84 is unsupported and falls back to OSMTILE. A map of something that is not the Earth needs a renderer that will accept the coordinate system it is given rather than assume one.

What the four cells are for, between them:

  • TMS tiles — <map-link tms rel="tile">, one attribute that counts tile rows from the bottom instead of the top.
  • A whole feature as a link — <map-geometry><map-a href="…">…</map-a></map-geometry>, including href="#zoom,longitude,latitude", which navigates within the map it is in rather than leaving the page.
  • Different representations at different scales — two features for the same girl, each with its own zoom range, only ever one of them drawn, hit-tested or focusable.
  • Declarative scaling past the last tile — <map-meta name="zoom" content="min=0,max=7"> over a tile set that stops at 4: a responsive image the layer decides about, not the page.

Related: TMS maps applies the same attribute to geographic content, and Progressive enhancement is the <area>-based image map this is the opposite number of.
