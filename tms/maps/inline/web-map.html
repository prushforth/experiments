Experiments

TMS maps, declared inline in a <map is="web-map">

The same TMS fire weather tiles, WMS basemap and query, hosted by the customized built-in <map>. The layer markup is unchanged: a TMS tile set is a property of the <map-link>, not of the element showing it.

Feature tags

Content type Inline Remote
Root element <mapml-viewer> <map is="web-map">

MapML.js (Leaflet)

The <map> hosts its chrome on a child <div class="mapml-web-map">; the tiles, the basemap and the query popup are the same as in the <mapml-viewer> frame.

MapML-MapLibre

The same tms tile scheme on the source, and the same 404s for tiles outside the service's coverage. In WebKit the customized built-in never upgrades, in this column as in the other two.

MapML-OpenLayers

One viewer implementation serves both root elements, so the row flip, the clipped basemap request and the query are the same code in this frame as in the <mapml-viewer> one.
