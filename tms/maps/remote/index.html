TMS maps, from remote MapML

The same map, except that the page says only <map-layer src="fire- weather.mapml">. The two extents, the TMS template, the query template and the basemap's licence are in that document, which is how a service could publish its tile set for anyone to put on a page.

MapML.js (Leaflet)

The document names itself with <map-title>, so the layer control reads Canada Base Map + Fire Weather Index without the page saying so.

MapML-MapLibre

Remote MapML is XHTML, so the bare tms attribute has to be written tms="tms": the same declaration, spelled the way an XML parser requires, and the same tms tile scheme once it reaches MapLibre.

MapML-OpenLayers

The query link arrives in the layer's shadow root with the rest of the document and still answers clicks on the map: a fetched <map-extent> is as queryable as an inline one.

Each frame fetches its own copy of fire-weather.mapml, so that View code and Open full page show a self-contained example; the three copies are identical.
